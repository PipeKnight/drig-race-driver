## Boundary and ownership

Their solved physical bodies and complete stable contact pools must agree. The disabled branch supplies the pre-event car, physical state, global RNG and all 20 contact slots. The enabled branch supplies the complete expected post-event car and RNG. Its frame prefix must agree with the owner. The enabled result is carried into the next disabled branch, so subsequent physics uses the same accumulated damage state. Both private query caches have already seen the same current inputs.

Source material words remain opaque; no captured pointer is followed.

The original wrapper first dispatches the transient prefix and clears its count, then visits an owned geometry-pair carrier containing the supplied suffix. That carrier represents the current supplied geometry, not a recovered persistent collision factory. Its count remains unchanged in the original. The final output checks the consumed prefix count, suffix count, complete projected car/physical buffers and all stable contact slots. Canonical source identities replace the owned native pointers explicitly. Canaried complete contexts, the extended car tail, physical padding and the complete mapped image are checked; lazy pages/protections are restored. There are no code replacements, original imports, entry-point or TLS execution.

This is a boundary replay of the complete original registered wrapper. `AD8D70`, original contact detection, arbitrary retained persistent chains, dynamic other-car responses, notification implementations and live asynchronous scheduling are outside the native probe. Full solver/producer equivalence remains supported only by the earlier separately scoped proofs. A matched wrapper result does not establish a whole original gameplay frame.
