# Donington source-sky environment lighting

15 October 2026, opt-in authored experiment, `--ibl source` (enhanced graphics, Donington scene and source sky required). Procedural IBL remains the CLI default while validating this experiment.

The visible source dome previously coexisted with an unrelated procedural Earth environment map. This can make the car and shaded track inconsistent with the sky shown on screen. The new path projects rays onto the actual purchased sky triangles, interpolates their original UVs and bilinearly samples BC1 color in linear light. It creates a private in-memory 256×256×6 sRGB cubemap; Bevy 0.19.1 generates 32×32 diffuse irradiance and roughness-filtered specular mips on GPU.

Cube face layout follows installed Bevy `utils.wgsl::sample_cube_dir`, including the Z flip used by `atmosphere/environment.wgsl` and the environment sampler. This is not an assumed panorama/equirectangular conversion. Both triangle winding directions are accepted, nearest positive intersection wins, positions are scaled uniformly for conditioning. Input counts/indices, BC1 block size and finite positions/UVs are bounded/validated.

Actual first bake: 205260 of 393216 rays intersect source geometry, zero upper-hemisphere misses. The missing lower hemisphere uses authored ground color RGB67/63/52; it is not a captured road reflection or original GRID radiometry. Intensity8000 cd/m² is an authored scale for LDR sky data. Visible background shader, sun direction/exposure and original EGO sky radiometry remain separate unresolved choices. No local buildings/cars are in this map; it is distant sky plus ground approximation.

`sky-ibl-source01.png` and `sky-ibl-procedural01.png`: matched native3840×2160/start camera, same sky/sun/materials. Both inspected, source variant is less washed out and shaded surfaces are darker. This is a visual observation, not proof of original exposure or completed reflection fidelity. First pilot source2883aa9 had a formatting-only working diff subsequently committed as e6539d1.
