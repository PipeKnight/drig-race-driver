# Supplied packed world query (F091)

`grid-world::packed_world::query` combines the verified grid collector with untransformed packed shape queries. The caller supplies stable shape IDs, grid cells, geometry and per-triangle materials. It is independent Rust logic; source grid population remains separate.

The original `96b7f0` forms an ordered X/Z rectangle from both segment endpoints and collects at most **25 first-seen unique candidates**. It dispatches each candidate through `a6a530`, whose type-11 table entry invokes `b23800`. Every shape receives the original full segment; the world loop does not shorten it after a hit or stop at zero fraction. All candidates share the rejecting-plane cache. A strictly smaller fraction replaces the chosen shape; equal fractions keep the first shape. Within a shape, the verified leaf consumer can instead replace equal hits with a later triangle. An inactive registry returns no hit before traversal.

Native IDs must be nonzero/unique and candidates must exist in the supplied shape table. Finite input, ≤512 shapes and the existing bounded mesh/grid validation are authored restrictions. Nonzero shape transforms, other dispatch types, original population and synchronized live contacts are outside this implementation.
