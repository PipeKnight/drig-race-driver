# DRIG capture backlog

Open work parked until a live recording of the original grid.exe (research copy, see docs/OWNER_ASSISTED_TESTING.md and docs/GAMEPLAY_RECORDING_GUIDE.md). Gathered on 2026-10-21 (F532) from the log entries (F300 onwards) and docs/FIDELITY_BACKLOG.md by grepping for live-capture requests; rows trace to the cited entries and docs. When a capture lands, set the row's status and cite the log entry; add new parked items as rows.

How to use:
- A capture needs the owner's go and a free desktop. Run the hash-checked research copy (SHA-256 b1da1b2d…aece34a6), never the Steam install. Snapshot the 19 user files first, then restore and hash-check them afterwards. Ask the owner to set a 60 Hz display, because the config vsync lock does not hold (F419, F450). Record world +0x7C8 for every capture.
- Before the race: pause on the grid and run `tools/find_reference_vehicle_manager.ps1` to get the manager JSON. Then use the samplers. They open the process read-only. `tools/run_grid_macro.ps1` / `tools/grid_macros.ahk` send menu keys only, and never while the owner drives. Rows marked "owner-driven" need the owner at the wheel (docs/GAMEPLAY_RECORDING_GUIDE.md).
- Keep evidence under `local/` (for example `local/driving/<topic>-<date>/`) and run `tools/dedup_hardlinks.py --apply` on it. Then add a log entry (`py -I tools/log_entry.py new`) with the PID, setup, evidence path and result, and set the row's status here.
- Several AI rows need a track the Touring Cars Race Day list does not offer. Jarama is not on that list. Washington, Spa, Milan, Le Mans and the Nürburgring are (F450).
