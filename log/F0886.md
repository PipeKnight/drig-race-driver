F886 Transparent phase: bind groups merged once per render pass in vendored wgpu-core (2026-11-23, Claude Code).
- Task (coordinator): Donington 2560 Enhanced `r_encode` is 4.2-4.9 ms with about 286-337 transparent draws. Target: at least 0.7 ms off the render thread, as a general fix, with no visible change (glass blend order included) and no merged or removed car parts.
- Observation (`GRID_TRN_DUMP=1`, a new diagnostic in `frame_split.rs`): Donington start has 125-152 transparent draws per frame in Enhanced, mostly car-glass panes (F876) alternating with their reflection overlays. About 97 % of the 125-150 pipeline switches and bind-group switches are `pane>overlay` or `overlay>pane`. Sorting by material would change the glass blend order (F865), and merging meshes would merge car parts, so the draws stay as they are.
- Cause (wgpu-core 29.0.4, `command/pass.rs`): every `set_bind_group` in a render pass merges the bind group's whole resource list into the pass's usage scope and registers its memory-init actions again. A bindless material slab holds 60-100+ resources, so each switch repeats work that cannot change inside one pass.
- Fix: wgpu-core 29.0.4 vendored in `third_party/wgpu-core` (`[patch.crates-io]`, `third_party/README.md`). A render pass remembers the bind groups it has merged and init-checked (`BindDedupe`, keyed by `Arc` address; the pass keeps each one alive) and does both once. The raw bind, tracker insert and validation still run on every call. Compute passes are unchanged. `GRID_WGPU_BIND_DEDUPE=0` restores the upstream path. It applies to every pass, track, car and material.
- Image check (`local/ab/crops-dd.ps1`, 2560x1440 fixed-step, one exe, dedupe off vs on plus a second on-run as noise): Donington and Spa base/Enhanced ticks 600 and 1500, Haruna touge base/Enhanced tick 900. 0 px in all ten cases. Base Spa 600 first showed 1 px; a second off-run matched the on-images exactly, so that pixel was noise in the first off-run.
- Test: `crates/grid-app/tests/bind_dedupe.rs` (ignored, needs a GPU; the full prepush tier runs it): twelve overlapping alpha-blended quads alternating two material types, fresh textures, shadowed light; child processes with dedupe on and off must render identical frames 0, 1 and 8. Passed.
