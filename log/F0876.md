F876 Car-glass pane proxy material and lamp write guard (2026-11-20, Claude Code).
- Goal (coordinator, after F865): cut the transparent-pass encode cost of car-glass panes for every car and
  track with no visible change; detail and tables in docs/PERFORMANCE.md "Car-glass panes off the bindless
  slab (F876)".
- Cause (observation, frame_split `bl_std`/`bl_ovl`, kept as counters): each blended car pane sorts next to
  its reflection overlay, so the transparent pass re-binds the StandardMaterial slab (505 resources in
  Donington, 270 derby, 424 touge) for every pane; wgpu `CommandEncoder::finish` pays per bound resource.
- Rejected: a smaller StandardMaterial slab for everything (diagnostic `GRID_STD_SLAB_LIMIT`, removed):
  64/128/256 lowered the encoder tail only in Donington and broke opaque and shadow batches everywhere
  (derby 151.8 -> 145.3/146.0/148.5 fps, touge 146.4 -> 136.3/142.0/143.4).
- Rejected: a non-bindless copy per pane: Donington +9.09 fps, derby +1.60, touge -8.67 (`d_shadow`
  70.0 -> 83.8, the copies no longer batch in the shadow passes).
- Accepted: `crates/grid-app/src/pane_slab.rs`. Blended parts with `HasOverlay` get a `PaneDraw` copy
  (`ExtendedMaterial<StandardMaterial, PaneSlab>`, empty bindless extension, own small slab) that follows
  every source change in the same frame; the render world redirects the material instance once the copy is
  prepared (GPU mesh building path only). Same shader, so the same image.
- Found on the way: `lamp_signals::runtime::project` darkened and re-lit every owned lamp material each
  frame and re-assigned the same handle through `Mut`; with the copies touge lost ~20 fps (`r_bind`
  0.6 -> 1.6 ms, ~46 copies re-made per frame by a temporary counter, removed). Now it writes the final
  emission once and only on change, the bank image only on change, and the handle only when it differs
  (touge: 16 copies per whole run, 67 redirects). This was a per-frame re-prepare before the copies too:
  unpaired, touge "off" rose 133.0 -> 156.9 fps while derby and Donington rose ~7.5.
- Result (ab-pn5, alternating pairs copies off vs on, idle-guarded, 1280x800 baseline, 3000 ticks): touge
  +0.68 fps (enc_tail -0.14 ms), derby +1.90 (noisy), Donington pairs 2-3 +9.41/+8.80 (pair 1 invalid,
  rustc running); earlier clean ab-pn4 Donington +7.45 (+7.45, +7.53, +7.38), 1 % low +3.04, enc_tail
  -0.63 ms. GPU time unchanged. Matched fixed-step crops (Donington, Spa, derby, touge; baseline and
  Enhanced): 0 differing pixels in all seven, same as noise.
