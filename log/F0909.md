  - Windows `--game-root` checks of the exe, run from empty folders under the build lock and muted. Steam discovery cannot be made to fail on this PC: `install::steam_roots()` always adds `C:\Program Files (x86)\Steam`. The flag therefore pointed at a directory junction to the install (`mklink /J`, no admin rights). A log that names the junction path shows that the flag won.
    - `--list-tracks --game-root <junction>`: exit 0, 77 routes.
    - Race with only `--race --track donington --game-root <junction>`:
      - Log: `game_root path=<junction>`, `event=go`, `drive_script_complete ticks=300`.
      - No panics, no settings diagnostics, no asset errors.
      - AppData untouched; only `DRIG-data` beside the exe.
    - `--data-dir` whose settings.ini says `[game] root = C:\nonexistent-grid`, plus `--game-root <junction>`: the flag wins (`game_root path=<junction>`, race completed). Afterwards settings.ini still holds the wrong root, so the flag is not saved.
    - `--list-tracks --game-root C:\nonexistent-grid`: exit 0, no routes, no message. There is no fallback to Steam. The silent empty list predates F907: `event_menu::list_routes` builds an empty catalog from any folder that is not a GRID install, and a wrong `[game] root` does the same.
    - The only ERROR lines are the two `bevy_render::slab_allocator` "Use-after-free" errors that every run logs (row 139).
