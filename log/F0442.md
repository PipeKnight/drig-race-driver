F442 Track time of day, sky, fog and weather: the original's data and selection, a data model and a hand-off for the renderer (2026-10-19, Claude Code; coordinator's fidelity task 2, static analysis only, GRID not launched). Details: docs/TRACK_ENVIRONMENT.md. Evidence: this worktree's local/weather/ (decoded binary lighting files, track_model survey, Ghidra 12.1.4 read-only decomp w1/w2).
- Data [D]: one `lighting.xml` per track (7 text, the rest binary XML) plus the night presets of Haruna route_1/3/6/8/9 (skyscale 0, sun 90.5°, black fog); Shibuya is a night preset (skyscale 0.03). `track_model` flags: `supports_time_of_day` le_mans Route_0 only, `headlights_on` Haruna 1/3/6/8/9, `vehicle_lights_on` 28 rows (Haruna, Shibuya, Yokohama). Events and careers have no time or weather column; a route picks its environment.
- Weather [D]: the code supports rain (lighting `<WEATHER rainfall>` 0x72AC90, WeatherFxPlugin, `environment_rain` sound 0x5C7860, `rainEffectLevel` 0x9D01E0, an ambience parser with condition DRY/RAIN and timeOfDay DAY/NIGHT 0x4570E0), but no lighting file has WEATHER and `weather_fx.xml` disables rainfall, drops and wipers: every shipped race is dry. `sky_rain_*` scroll the sky's cloud layer only.
- Port: `grid_formats::track_environment` (`read_lighting` text and binary, `read_weather_fx`); `grid_tools::environment::Environment::for_route` (route lighting before the track's [I order], flags, `night()`, `vehicle_lights()`, `raining()`); `Environment::mode()` is F430's `time_of_day::Mode` from the same row (tested equal to `Mode::for_route`); grid-app `track_environment::TrackEnvironment` resource and `drive_environment` log line. Data only: no rendering change (Codex), the Le Mans clock stays F430's.
- Checks: see F441.
