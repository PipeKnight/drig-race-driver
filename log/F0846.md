Details and tables: docs/PERFORMANCE.md "Ground cover: stable billboard slots (F846)".
- Change (`crates/grid-app/src/ground_detail.rs`):
  - a `Slots` table holds which cover instance each slot of the padded asset draws; the async regather returns only the instance indices, and `apply` builds, packs and writes (`MeshStream::write_at`) only the runs of changed slots (runs closer than 8 slots joined; free slots get the padding billboard, limit 0, never drawn);
  - masked/A2C (`update`): kept instances keep their slot, new ones take the lowest free slot;
  - blended (`update_ordered`): keeps the gather's global order, which is the draw order; kept instances stay, new ones go into the slots before the next kept one; when the order does not fit, the gather is placed again centred and written whole.
