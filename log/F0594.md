- Research [O], docs/SPEECH_AUDIO_RESEARCH.md (new). Static only: grid_re decompile/dis and the purchased `audio/eventSpeech.bin` / `audioEventSpeech.bin` decoded with the binary XML reader (private XML in `local/speech/`). GRID was not launched.
- The original's speech is data-driven:
  - `audio_event_speech_manager` evaluates event → group → message rules against about 400 parameters, filled by `audio_game_info_collector`;
  - the whole engine is now mapped: file formats, the 19 comparison operators, queue order, play percentage, expiry, preemption, minimum silence, commit, playback and reset.
- Key rules:
  - **Trigger.** Every frame, each enabled event, group and message is tested. A candidate must:
    - pass the repetition threshold (s since it last played);
    - not be among the last 5 played (`previousQueue`);
    - respect the play-count limits, the exclusive groups and the message's own conditions;
    - pass a random percentage roll: 100 for priority < 2, else max(100 − plays × 5 × priority, 100/priority).
  - **Queue.** The queue is ordered by event priority, then message priority; lower numbers come first and priority 0 goes to the front. It holds at most 5 messages, and a message expires after max(queueValue, keepInQueueTime).
  - **Choice of line.** The speech's `long` file plays first; after that, a uniform random variation. A line that matches the previous file is dropped.
  - **No overlap:**
    - one speech voice;
    - a new line needs the voice free and now > (last line start + 2.5 s) + minimumSilence 7 s, unless `ignoreMinimumSilence` or `isFinalMessage`;
    - priority-0 messages preempt;
    - after an `isFinalMessage` (every finish line), nothing more plays until the next reset;
    - lines play in the Talking mix mode.
- Parameters: the car record behind playerTime and carPos±1Time is race time ÷ race progress, i.e. an average lap time. The documented "gaps" compare average lap times. Time in position, best position, collision timers and totalDam (0x424650) are mapped as well.
- Original quirks, to be ported 1:1 (deterministic):
  - `playerStartPosPercentage` uses integer division (0x452A42). It is 0 except from the last grid slot (100), so only `playerGridPosLast` of the grid-position lines can play.
  - `onStartingGrid` is only set by a race restart while racing, and that call also sets `startAfterRestart`. Grid lines therefore play only after a restart, and `startingGridGen` (newbie, 2nd visit, veteran) is unreachable.
  - The 8th–15th finish lines (`offPaceEnd`) name files that do not exist in 07_performance, so they are silent.
