F335 ETC2 texture cache for GPUs without BC (P8 follow-up, owner request) (2026-10-16, Claude Code). Details are in docs/PLATFORMS_AND_INPUT_RESEARCH.md 7.3.
- Without BC, a GPU with ETC2 now gets textures from a private KTX2 cache instead of the 6.5× RGBA8 decode. Path order: BC, then ETC2, then RGBA8. P5's diagnostics key texture_fallback is now off/on=rgba8/etc2 (legacy GRID_TEXTURE_FALLBACK=1|rgba8|etc2); docs/SETTINGS.md updated.
- New grid_formats::etc2: our own ETC2 RGB8/RGBA8 (EAC alpha) encoder and decoder covering all five RGB modes (individual, differential, T, H, planar), with steering bits for T/H/planar. No new crate. ETC2 was chosen over ASTC because no maintained pure-Rust ASTC encoder was found (web search 2026-10-16).
- New grid-app texture_cache: decodes the BC levels, encodes each level in parallel and writes `<fnv64 of DDS>-<len>-v1.ktx2` to settings::data_dir()/texture-cache (local/texture-cache in the checkout). Later loads go through Bevy's KTX2 loader, already enabled by the `3d` feature. Textures with any non-opaque texel use RGBA8 + EAC; otherwise RGB8.
- [V] On the i7-12700's Intel UHD 770 iGPU (Vulkan, WGPU_ADAPTER_NAME), which exposes ETC2 and ASTC; the RTX 4070 has neither. Evidence: worktree local/texture-fallback/etc2/.
  - Texel memory equals BC: car 9.29 MB, Donington 46.67 MB, 12-car race 92.14 MB (BC 91.40, RGBA8 593.12).
  - Frame PSNR against BC on the same GPU: car 50.8, Donington 45.3, race 43.9 dB. Cold and warm cache renders are byte-identical; there are no visible artefacts.
  - Load: race cold 9.2 s (encode 8.0 s, all threads, 16 other compile processes running), warm 0.46 s. The cache is 495 files, 78.4 MB.
  - Forced ETC2 on the RTX 4070 falls back to RGBA8 and logs why.
- New asset test etc2_quality_on_installed_textures (455 textures: Lacetti, livery 00, Donington tracksplit and objectstextures): overall 36.49 dB, worst 28.65 dB (a decal normal map); single-threaded encode about 10–12 s.
- New unit tests cover the codec, Bevy reading our KTX2, threaded = single-threaded encoding, and path choice.
- Checks: clippy --workspace --all-targets -D warnings clean; cargo test --workspace --release -- --include-ignored with absolute GRID_* paths: 392 passed, 0 failed (rebased on a7f7112); cargo/rustc 1.99.0.
- Not done: no phone run, no ASTC, no RG11 path for normal maps (none are bound yet), and no separate import tool with progress (P10). The playable was not rebuilt.
