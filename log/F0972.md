- p6w: the parallel finish keeps a small edge while the phone throttles and costs no extra heat. One soak per arm, so the edge is inside a plausible spread.
- p1, p2: neutral; the differences are smaller than the spread between runs of the same arm.
- p3: inconclusive. Run 2 started 5 °C cooler (thermal status 0) and gave 42/40 FPS; run 4, started at 36.9 °C, gave 40/31 against lean 39/36 and 38/36. To be repeated.
- p4: neutral or slightly worse. The `cpu_place event=uclamp ... util_min=512` line reports `result=1` while the pin lines report `result=0`; if 1 is a failure, uclamp never applied [I]. Not checked in the code yet.
- p5: a win, both B runs beat both A runs (42/38 and 42/38 vs 39/32 and 39/33). CPU time moves from the pool to the main and render threads (cpu_main_run 4.7 → 19.4, cpu_render_run 9.8 → 19.0, cpu_pool_run 53.2 → 16.7 per cent of a core), and the total falls from about 67.7 to 55.1, so less heat is likely [I]. A throttled 15-minute repeat is queued.
