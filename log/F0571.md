- Owner's report [O]: APKs 3cdbf523a7f0 never drop below 30 FPS, but the render height never rises above 480.
- Phone log `log-20261026-125712.txt` (profile APK, Donington 12 bmw, Adreno 740; worktree `local/playtest/phone-20261026/`):
  - [O] `render_dynamic` went 720 -> 480 from 14.7 s to 16.7 s; frame 41.3 -> 36.0 ms; work_ms 1.3-1.8.
  - [O] Profile windows from 40 s on: frame 23-27 ms, Main 18-24 ms, Render 21-25 ms. Compute threads work about 6 ms each per frame; the render thread works 8.5-10.7 of 23-26 ms in spans.
  - [O] drive_tick 4.4-9.4 ms per frame at 1.5-1.7 calls.

- Change (`crates/grid-app/src/render_scale.rs`, Auto only, so the desktop default `native` is unaffected):
  - Each step down is a probe. After `PROBE_SECONDS` = 1 s, the smoothed frame must have gained `GPU_SHARE` = 0.5 of a pixel-bound frame's gain (`before x (1 - (to/from)^2)`).
  - Otherwise: back to the ceiling (720), hold `HOLD_SECONDS` = 60 s, then probe again.
  - Log `render_dynamic version=2 ... reason=ineffective probe_gain_ms= pixel_gain_ms=`; the install line lists probe_s, gpu_share, hold_s.
  - Policy unchanged: resolution is the only quality cut, 480-720, MSAA on.
