F636 Phone: 60 FPS cap and 60 Hz refresh by default (2026-10-28, Claude Code).
- Request: a friend with a fast phone reported that the game runs at 120 FPS and that tilt steering stops working at 120. The owner: target 60 FPS on the phone and do not go above it.
- Observation (code, before this change): no frame cap on Android; `[video] refresh_hz` defaulted to `system` (no `ANativeWindow_setFrameRate` hint), present mode Fifo. On a 120 Hz panel the app therefore rendered at up to 120 FPS, which matches the friend's report [I: no log from that phone].
- Tilt: `android_sensor.rs` reads the game rotation vector at 100 Hz on its own thread and keeps the latest reading; `touch_controls` reads it without consuming it, and `tilt::Tracker::update` smooths with the real frame `dt`. Nothing in this code depends on the frame rate, so the "tilt stops at 120" report is not explained [I]. The friend's log (`Download/GRID-Reassembly/log-*.txt`, lines `drive_tilt ...`, `android_frame_rate ...`, `frame_stats ...`) is needed to tell; at 60 FPS by default the case should no longer arise.
- Change (AUTHORED):
  - `settings::Settings::video_refresh_hz`: with the mobile preset the default is 60 Hz (`MOBILE_REFRESH_HZ`). The Video screen now also writes `[video] refresh_hz_version = 1` (`REFRESH_HZ_VERSION`); a `refresh_hz = system` saved without it predates the default and reads as 60 Hz. A chosen 60/90/120 stays. The desktop keeps `system` (the hint and the cap are Android-only), so the desktop picture and timing are unchanged.
  - `android_display::cap` (Last schedule): sleeps so frames are due every 1/hz s on a fixed schedule (`render_scale::pace`; a slightly late frame lets the next catch up, more than a period late restarts the schedule). The 60 Hz hint is still sent, but a panel may keep 120 Hz, so the hint alone does not cap. `System` has neither hint nor cap. Logged as `android_frame_cap hz=...`.
  - The dynamic render height already judges frames against 60 FPS (on time below 17.2 ms), so capped frames count as on time [I].
- Docs: docs/ANDROID.md "Display rate options" and the Video screen table.

Pre-push: `prepush: tier crate [grid-app]`; sanity pass, clippy-crates pass (16 s), test-grid-app pass (331 passed, 0 failed); passed in 82 s.
