F781 Night level, tree sheet shadows, world clear colour (2026-11-10, Claude Code).
- Coordinator task after F776, four shared fixes for every route: night ambient and sun level,
  the Shibuya ripple emissive, shadow bands on the Le Mans canopies and Spa forests, and the
  Detroit clear colour. All four go through shared code; no route is named in code.
- Night level (docs/TRACK_ENVIRONMENT.md §3.2):
  - Before, every preset's `backlight_suncolour` peak was mapped to the 18,000 lux sun. A dim night
    sun therefore raised the fill, Phong, emissive and night-light units: Haruna's forced night was
    about 12 times too bright, Shibuya about 4 times.
  - `graphics::sun_reference` = max(peak, `DAYLIGHT_SUN_PEAK` 1.99, the dimmest shipped day preset),
    and the sun's lux is scaled by `sun_level`. Log: Haruna r1 `level=0.0847`, Shibuya r0 `0.2365`,
    Spa and Le Mans 1.0. Day routes keep their unit.
  - New `timeline_lighting.rs` applies the `daynight.xml` timeline's light values at the event
    clock, or at the static start in a static scene. This covers the static Le Mans night scene
    that kept the day sun. Before, only the sky followed the clock in the default path.
    Le Mans r0 log: `timeline_lighting apply t=0.6250 sun_lux=18162 ambient=2241.4`.
- Ripple: `object_emissive_ripple` binds a map, but nothing sets its `EmissiveTime`. The group saves
  no defaults, and the only users of the string are 0x9790E0 and 0x96E430. So its emissive adds
  nothing in the original [I: an unset constant is assumed to be zero]. The port already left it
  out. Only the docs and the audit flag wording changed (docs/GRAPHICS_AUDIT.md).
- Shadow bands, root cause [D]:
  - The tree setup 0x970C40 (new symbols row `tree_shader_select`) maps `treesheet_*` to the
    shaderpack group `tree_sheet(_shadowed)`.
  - In `shaderpack.pssg` that group has only the pass masks 1 and 2. Every other tree group has a
    mask-4 `csm_depth_opaque` shadow pass. So tree sheets cast no sun shadow in the original.
  - In the port, the sheets' shadow twins and casters cast the vertical dark bands in the Le Mans
    canopies and the near-black Spa forest interiors.
  - Fix: `source_trees::casts_sun_shadow`. Sheets get no `ShadowTwin` and are `NotShadowCaster`.
    Test: `tree_sheets_cast_no_sun_shadow`. Details: docs/SOURCE_VEGETATION.md.
- Detroit [D, with I as noted]:
  - The world pass 0x5C8080 keeps the base render pass's clear colour (0.14, 0.11, 0.06) from
    0x64BCD0, and the dispatch 0x63AEB0 clears with it every frame.
  - The race scene now clears to that colour, read as sRGB [I]; before, it cleared to blue-grey.
    The hole in the Detroit r0/r1 ground data is in the original data and stays. The audit mode
    keeps its magenta sentinel.
