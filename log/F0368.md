- All AUTHORED (GRID has no tilt or touch input); original rules reused where they exist:
  - `input.rs`: `Source::Touch` (0/1) and `Source::Tilt` (bi-axis 0.5 + 0.5·tilt); `ActionMap::touch`: pedals uniPos dz 0 sat 1 and buttons with the constructor defaults (the keyboard preset's calibrations, exact 0/1); tilt to Steer Left biLower / Steer Right biUpper dz 0.05 sat 1.0 (4CC630's steering values for controller types 1–3; the pad stick's 0.2 is for stick drift). The Advanced Controls overrides apply on top. Menu Back also exits a replay. Assisted steering class (keyboard/pad), 827D10 and the shift queue unchanged.
  - `tilt.rs` (pure): up vector from the game rotation vector or accelerometer; angle about the screen normal (lean does not steer); landscape inferred from gravity (135° flip threshold, no rotation API without JNI); flat phone keeps the last value; tilt = clamp((angle − neutral)/maxAngle); one-pole low-pass τ 0.05 s; neutral from the first reading, CENTRE, or `tilt_neutral`.
  - `touch_controls.rs`: zone layout and hit test (pure), Bevy `Touches` glue, UI nodes under the race HUD and pause menu (`GlobalZIndex(-1)`); drive layer GAS/BRAKE bottom corners, HAND, GEAR ± (manual only), II and CENTRE top centre, VIEW/LOOK bottom centre, a tilt bar; menu layer (paused, post-race, replay) UP/DOWN/</> left, OK/BACK right. At most 8 touches. In touch mode `UiScale` = HUD camera height / 720 (≤ 1).
  - `android_sensor.rs` (Android only): `ndk-sys` 0.6 ASensorManager on its own looper thread, `TYPE_GAME_ROTATION_VECTOR` 100 Hz (accelerometer fallback), off while suspended. `android::touch_screen()` from AConfiguration.
  - Settings `[input] touch=auto|on|off`, `tilt`, `tilt_max_angle` (30), `tilt_neutral` (auto), `tilt_smoothing` (0.05); printed only when set, so the desktop `drive_input` line is unchanged. `tools/push_android_data.ps1` writes them instead of `autopilot = on`.
