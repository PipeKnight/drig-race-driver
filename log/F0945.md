F945 Claude Code token audit script and findings (2026-11-26, Claude Code).
- New `tools/claude_usage_audit.py`: offline, standard-library analyzer of this project's Claude Code transcripts (`~/.claude/projects/C--Dev-Reassembly*/**/*.jsonl`, sessions, child sessions in worktrees and subagents), streamed line by line. Mirrors `tools/codex_usage_audit.py` (F939/F940): `--since`/`--until`, JSON summary, one verdict line; `--out FILE`, `--public` (drops every token figure). It measures, per session and in total: API calls (deduplicated by message id across forks), context per call, cache rebuild events by cause (first call, after compaction, idle gap over the cache TTL, model change), tool calls by name, shell commands by category (observe, build_test, run, git, git_check, edit, read, other), large tool results, whole-file and repeated reads, images, compactions, turns by origin, idle and "still waiting" turns, cross-session message counts and sizes, re-injected attachments, top sessions and top turns.
- Findings and ranked recommendations: [docs/CLAUDE_TOKEN_AUDIT.md](../docs/CLAUDE_TOKEN_AUDIT.md). Raw JSON (with private token figures) under ignored `local/claude-audit/` (`all.json`, `since-2026-11-06.json`, `since-2026-11-19.json`, `since-2026-11-19-public.json`); full run over 196 transcripts takes about 15 s per window.
- Observations (process counts and shares only): all transcripts 79,697 API calls in 121 sessions and 72 subagent transcripts; since 2026-11-19 9,677 calls. Shell calls that only observe: 3.2 % all-time, 2.6 % since 19 Nov (F733: 28 %). Shell `read` calls: 52 % since 19 Nov. Compactions: 784 all-time, one per 52 calls since 6 Nov. Idle turns since 19 Nov: 159 (158 of them coordinator `side-sessions-event` turns), 1.7 % of calls. Ten longest turns since 19 Nov: 114–272 calls each, 18 % of all calls.
- Interpretation: polling is solved; the cost now follows calls × context per call. The largest levers are fewer, bigger read commands, a shorter per-compaction preamble (skill listing, AGENTS.md + memory index, deferred-tool list of unused connectors: about 50 KB per injection) and a compacted, quiet coordinator while it waits. Proposed AGENTS.md wording is in the doc; no rule was changed here.
- Uncertainty: shell categories come from a heuristic classifier of the command text (first command of each pipeline); "idle" means a short non-human turn without tools, which can include a legitimate one-line answer. Image token estimates use the public API resize rule.
