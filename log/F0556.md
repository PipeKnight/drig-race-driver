F556 Dynamic render height 480-720 rows on Android; UI, HUD and OSD drawn at the window's resolution (2026-10-22, Claude Code, P12 performance; Owner 2026-10-22: dynamic resolution from 480 to 720 rows).
- render_scale::Dynamic (mobile preset): render height between 480 rows and the row setting (default 720, the ceiling; a saved Video Render height count replaces it, native disables scaling); down 48 rows per 0.5 s while the smoothed frame time is above 18 ms and the main schedule (First..Last) is under 80 % of the frame and under 14 ms; up 24 rows after 3 s below 17.2 ms; a height that ran late is blocked for 15 s; frames above 100 ms and the first 3 s ignored. GRID_DYNAMIC_RES=0 fixes the height. Details: [PERFORMANCE.md](../docs/PERFORMANCE.md) "Dynamic render height (F556)".
- UI at full resolution: while the scaled image is shown, UI roots aimed at the 3D camera move to the window camera (render_scale::ui_on_window, which logs render_scale ui_roots), the window camera is the default UI camera, the OSD image follows the window size (osd_scene::resize), and touch UiScale reads the UI camera (touch_controls::ui_scale). The desktop default (native) is unchanged.
