- Wheel, cause [O]: the cockpit, driver, camera, number and livery readers built lowercase names from the car stem (`interiors/vip/int_vip_anims.pssg`). The installation ships `int_VIP_anims.pssg`. NTFS ignores case and the phone's storage does not, so the optional interior animation load found nothing. The crowd readers had the same problem with names from the game's data: Washington's dataset names `cr_us_billboard.pssg`, the file is `cr_US_billboard.pssg`.
- Wheel, fix: `grid_tools::install::resolve_case` (exact name first, then the one directory entry that matches ignoring ASCII case, per path component). Every derived car, interior, driver, livery, number and crowd path goes through it: interior_anim, driver, cockpit, camera, car_numbers, team_livery, crowd_billboards, crowd_near, crowd_near/flag_bank. No car-specific code.
- Wheel, check: `push_android_data.ps1 -Stage` now makes the stage's `Grid` folder case-sensitive like Android storage (fsutil, read back; the script stops if it is off). `trace_bundle_files.ps1 -Stage` also fails on an *unread* file, one the event's desktop trace lists but the run did not open. `build_android.ps1` runs that check for every bundled APK. docs/ANDROID.md "Case (F921)".
