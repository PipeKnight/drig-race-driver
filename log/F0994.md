- `tools/push_main.ps1` (new): the AGENTS.md push flow in one command. It fetches and rebases (stops on `log/`/`PROJECT_LOG.md` resolved by `log_entry.py check --fix`; other conflicts abort), amends a renumbered entry as the owner and rewrites the old number in the commit message, runs `prepush -Plan`; when cargo steps will run it takes the build lock (tier limit + 10 min) and rebases again, runs prepush nested in that lock, fetches, and pushes HEAD:main before releasing the lock. When main moved it releases the lock and repeats (at most 5 rounds). Since every session's code gate runs under the same lock, no other session's code can reach main between its rebase and its push.
- `tools/prepush.ps1`: `.github/*` no longer enters the pass-cache key (only GitHub runs the workflow; its tier was already docs), so a CI-only commit on main no longer invalidates a cached pass.
- AGENTS.md push-flow and check-level bullets point to push_main; docs/TOOLCHAIN.md "Pushing to main (push_main.ps1)" describes the rounds; tools/index_files.py lists the script.
