- Original [D unless marked]:
  - `interior_set_backlight` (0x9FE6A0) sets the EmissiveMapScale of the interior's `backlight_shaders` to 0.3 when lit (any `emissive_scale` present; 0.15 without) and back to the file value when unlit;
  - at race start 0x596440 → 0xA08DA0 passes the track's `vehicle_lights_on` unless the route is a headlights route; on forced-night and day/night routes the night-lights pass (0x736020) lights the focus car while the light fade is up and 0x735BD0 turns it off at the fade's end; 0x602FE0 passes the lighting file's `headlights`, 0 on all 23 shipped files [V].
- Port (`dash.rs`):
  - `prepare` collects each backlight shader's parts, its TEmissiveMap and its file EmissiveMapScale (`material::read_constants`);
  - `backlight_on`: `Mode::ForcedNight` on, `Mode::Timeline` while the Le Mans headlights' intensity > 0, otherwise `Environment::vehicle_lights`;
  - the `backlight` system (after `attach` and `feed`) applies a state change to the parts and the displays' material copies: emissive map × scale × 2.7 (EmissiveFactor default [I]); it skips the initial off state when every file value is 0.
- [V data, `dash::tests::every_cockpit_backlight`, ignored, GRID_GAME_ROOT] all 43 cockpits have a backlight shader with an emissive map and parts; 10 (911, c6r, ccg, ccx, cre, df3, fmj, je4, spk, stk) save a non-zero unlit value (1, and 10 on one fmj shader), so they glow by day and dim to 0.3 when lit, as the original's code reads.
