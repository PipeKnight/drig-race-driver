F881 Pane copies gated on StandardMaterial bindless; DX12 vs Vulkan A/B (2026-11-20, Claude Code).
- Goal (coordinator): fix the F876 regression on devices where StandardMaterial is not bindless, check every other
  ExtendedMaterial for the same base/extension mismatch, test the non-bindless decision, then the DX12 A/B
  asked before F876. Detail and tables: docs/PERFORMANCE.md "DX12 against Vulkan, and the pane copies on
  non-bindless devices (F881)".
- Cause (observation, then reading Bevy 0.19.1): with `WGPU_BACKEND=dx12` Donington quit at once with a wgpu
  validation error (bind group 14 entries, layout 15). On DX12 StandardMaterial is non-bindless: the device
  allows 2048 sampler binding-array elements per stage, below StandardMaterial's need (it has no buffer binding
  arrays, so DX12's missing `BUFFER_BINDING_ARRAY` is not the reason; my first reading said it was, the test
  showed otherwise). The data-only `PaneSlab` has no samplers and counts itself bindless;
  `ExtendedMaterial` forces both halves non-bindless only when the whole material is. The derby ran without an
  error before the fix; why is not established.
- Fix: `crates/grid-app/src/pane_slab.rs` `copies_enabled(device)` =
  `StandardMaterial::bindless_supported && PaneSlab::bindless_supported`, evaluated once from `RenderDevice`
  as a run condition of the copy systems (log line `pane_slab version=1 enabled=...`). Off: the panes draw as
  before F876. Observed: DX12 Donington runs, 0 validation errors, `enabled=false`; Vulkan `enabled=true`.
- Audit (reading the derives): the other grid-app `ExtendedMaterial`s (crowd preview, foundation backing and
  front, ground detail, light shafts, ornament LOD, paint environment, sidewall filter, skid marks) declare no
  `#[bindless]`, so they are non-bindless as a whole; `car_reflection_overlay` is a plain bindless Material.
  No other mismatch; derby DX12 (overlays on) ran clean.
- Test: `copies_run_only_where_standard_material_is_bindless` builds real wgpu devices (Vulkan, Vulkan with
  the sampler binding-array limit set to 1, DX12; skips what a machine lacks) and checks the gate equals
  StandardMaterial's condition, and that the lowered-limit device has the extension bindless, the base not
  and no copies. Result here: 3 devices, pass (Vulkan copies=true; lowered limit and DX12 copies=false,
  extension_bindless=true; DX12 buffer_arrays=false sampler_array_elements=2048).
- Rejected: a DX12 render-smoke step in prepush. The offscreen capture times out on DX12 (`render capture
  timed out`, 120 s budget) with both the F876 and the fixed build, no validation error; the 8 matched DX12
  crops timed out the same way, two logging `slab_allocator: Use-after-free ... unallocated key`. Open: DX12
  offscreen capture.
- DX12 A/B (1280x800 baseline, 3000 ticks, 3 alternating pairs under the build lock): DX12 3-4x slower in
  every cell. Clean, before the fix, derby: 157.64 -> 48.67 fps, 1 % low 123.93 -> 31.76, GPU 2.29 -> 6.15 ms,
  render 5.79 -> 26.96 ms, r_encode 2.31 -> 5.44 ms, material switches 10 -> 203. Fixed build (machine busy
  with an owner game, deltas consistent per pair): derby 123.98 -> 38.17 fps, Donington 99.81 -> 24.33,
  render 9.47 -> 46.41 ms, material switches 146 -> 252. Timestamp queries work on DX12. No default change.
- Checks: prepush tier crate passed in 727 s (sanity pass, clippy-crates pass, test-grid-app 1012 passed 0 failed,
  build-grid-app pass, render-smoke pass; local/prepush/20261120-120507). The first run failed Clippy
  `type_complexity` on the F876 `assign` query (now a `Reassigned` filter alias).
