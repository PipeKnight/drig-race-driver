F714 F710 skinned-mesh render regression fixed; prepush render smoke (2026-11-03, Claude (session collision-sweep); Coordinator: every grid-app render on origin/main since F710 exits with a wgpu validation error, fix at the root, verify windowed and offscreen on two tracks plus a break, add a render smoke to prepush).
- Regression [V]: after d848db81 (F710) a static render (`--route tracks/usa/washington/route_0 --scene donington --camera 214,2.4,874 --look-at 223,1.0,893 --render`) exited 1 with "Expected entry with binding 1" for the skinned mesh layout in the prepass (`local/skin-regress/w0-static.log` before the fix). Cause: the damage meshes carry `ATTRIBUTE_JOINT_INDEX`/`WEIGHT`, which selects Bevy's skinned pipeline layout, but F710 inserted `SkinnedMesh` in `dynamic_props::tag`, which is installed only in the drive system set and runs a frame after the spawn. In static scenes the skin was never attached, so every skinned draw had no skin bind group; in drive it came one frame late.
- Fix: `dynamic_props::attach_skin` spawns the joint entities and inserts `SkinnedMesh` (and `NoFrustumCulling`) in the same command flush that spawns the part entity in `setup`, for static and drive scenes alike. `PieceSkins` resource and the attach in `tag` removed.
