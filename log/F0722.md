  - `x = -4 atan2(d.v6, d.v4)/pi`, with `d` the direction to the eye;
  - view A = `ceil(x) + 1` at U offset `view/8`, view B one eighth further, wrapping with the sampler;
  - weight `frac(x)`;
  - the pixel program lerps colour, alpha and the two decoded atlas normals by that weight.
- Port:
  - `source_trees::atlas_view` returns view `floor(x + 2)` and the weight;
  - each frame the CPU writes view A into UV0 and the weight into UV1.x (UV1's offsets are only read on the CPU);
  - `tree_cards.wgsl` samples both views for colour, alpha and normal;
  - it overrides the prepass too, so depth and motion use the same blended alpha.
