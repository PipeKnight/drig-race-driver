F733 Token retro: where the tokens go; AGENTS.md token rules; earlier auto-compact (2026-11-05, Claude Code).
- The owner asked for a retro on saving tokens and improving the process ("какие ещё способы экономии токенов и в целом оптимизации нашей работы ты сейчас видишь"). They dropped the rented-server idea; all work stays local. They approved all seven proposals ("Все семь").
- Measured over the Claude transcripts of this project (~/.claude/projects, 2026-10-29 to 2026-11-05) with a one-off script (scratchpad, not kept):
  - totals: 2.79 billion cache-read tokens, 33.9M cache-write, 5.8M output, 10,496 model calls. The average context per call was about 280k tokens;
  - the busiest child sessions read 230–530M tokens each. One idle session's lifetime cost line showed 452M cache reads;
  - about 2,450 of about 8,600 shell calls (28 %) only waited or watched: 1,869 log tails, 411 sleep/until/while loops, 172 status checks. Each of these re-reads the whole context;
  - 345 images were read into contexts, and there were 44 compactions.
  - [I] At the usual price ratios (cache read 0.1, cache write 1.25–2, output 5 times the input price), cache reads are about 70 % of the cost. Halving the average context saves about a third.
- Changes:
  1. AGENTS.md has a new section, "Token economy". It sets rules for no polling, verdicts instead of logs, fewer round trips, images, and tests for interactive-only modes. The coordinator gives one topic per session and compacts or starts fresh before a new task.
  2. Earlier auto-compact for this project: the main checkout's `.claude/settings.local.json` sets `autoCompactWindow` 200000 (the user settings keep 500000 for the owner's other projects). The file is local and excluded through `.git/info/exclude`. Running sessions pick it up when their process restarts.
  3. Idle sessions can be compacted from outside with the bundled CLI: `claude.exe -p "/compact" --resume <uuid>` from the session's cwd, but only while no process holds that session. A message containing "/compact" arrives as text and does nothing. The standalone CLI said "Not logged in"; the owner will log it in once.
