F941 AGENTS.md: Codex waits use one long yield, no 1-second polling (2026-11-26, Claude Code).
- Owner request (26 November 2026, after the F940 audit): add an explicit rule against 1-second polling to the AGENTS.md "Codex" section.
- Change: the `write_stdin` bullet in "Codex" now also covers code-mode `wait` on a running cell: one wait whose `yield_time_ms` covers the expected run time (or the tool maximum), never a series of 1-second waits or empty `write_stdin` calls on the same cell or session.
- Evidence: F940 counted call types only. About one Codex call in four only waited. The most common `yield_time_ms` was 1000, and many waits repeated the same cell within a turn.
