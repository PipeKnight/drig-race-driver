- Phone log F376 [V]: Bevy logs "GPU clustering isn't supported on this device; falling back to CPU clustering". Bevy 0.19.1 hard-codes that for every Android build (`make_global_cluster_settings`: `!cfg!(target_os = "android")`).
- New grid-app diagnostic `GRID_CPU_CLUSTERING=1`: sets Bevy's documented `GlobalClusterSettings::gpu_clustering = None` at startup, so the desktop takes the phone's clustering path (rendering only; logs `perf_clustering mode=cpu`). tools/chrome_trace_summary.py now also groups exclusive system time by kind.
- Desktop solo traces (Bevy trace_chrome, 1280 × 800, baseline preset, steady state) [V].
  - CPU clustering costs 0.34 ms of CPU per frame, against 1.16 ms for the GPU path's CPU-side work: clustering is not the phone's problem.
  - Render thread 8.8 ms per frame, against 5.8 ms main plus 1.1 ms extract; `drive_tick` 1.0 ms. Even solo, the render thread is the longest CPU path.
  - Work by kind (CPU run, all threads): batching/instance buffers 1.85 ms, mesh upload/allocation 1.82 (`allocate_and_free_meshes` 1.51), bind groups/prepare 1.28, specialize/queue 1.01, visibility 0.99, simulation 0.98, shadows 0.75, extraction 0.64, UI 0.61, pass encoding 0.59.
  - The GPU-clustering run was more disturbed (p95 29.7 vs 21.1 ms), so its totals are inflated.
- [I] A phone core 3–4× slower than an i7-12700 P-core puts the render thread alone at about 26–35 ms, which fits the measured ~35 ms frames.
- Per-frame mesh replacement [V code]: `source_trees` re-faces every foliage billboard mesh each frame, `tyre_smoke` rebuilds every smoke group mesh each frame, and `ground_detail::present` rebuilds whenever the camera moves past its threshold. Each is a free, reallocate and upload on the render thread. Graphics files, not changed here.
- Multithreading cannot shorten this much more: Bevy already runs render systems in parallel and pipelines the render thread. The levers are less render work: no per-frame mesh replacement, fewer shadow cascades or a smaller map on the phone, fewer separate meshes.
